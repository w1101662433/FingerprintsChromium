# 成品功能

主要功能：

每次启动chrome.exe时，浏览器随机生成一个新指纹。

可选参数：

`--fingerprints=12341234`（随机数种子,最大9个9），可以固定住指纹，每个种子对应一个不同指纹。

`--timezone=Asia/Hong_Kong` 修改时区。

`--ignores=tls,fonts` 保留原生的tls和fonts指纹，不做改变。可选值有：--ignores=fonts,webgpu,webgl,canvas,audio,clientrects,screen,tls,useragent,video,svg
